# Result data status

Stage 1 retains the completed narrative reports in `docs/` and their PNGs
in `docs/figures/`. Compact numerical figure inputs and portable run records
are not yet included. Do not infer that the full figures can already be
regenerated from this candidate alone.

Before release, add reviewed sweep comparison tables, reversal summary and
histogram tables, permitted archived-data evidence extracts, and provenance
and checksums. Large raw trajectories should be supplied separately as a
versioned result archive rather than mixed with executable build outputs.
